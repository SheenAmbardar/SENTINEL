# 🛡️ SENTINEL Defence Analytics Dashboard

## Strategic Event & National Threat Intelligence Evaluation Log

## Overview

SENTINEL is a Python-based defence incident analytics dashboard designed to analyze security incidents using data analytics and visualization techniques.

The project generates, processes, analyzes, and visualizes defence-related incident data to identify patterns in threats, response time, regional distribution, and equipment usage.

---

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Streamlit

---

## Project Features

### Data Analytics
- Incident frequency analysis
- State-wise threat analysis
- Threat level distribution
- Response time evaluation
- Equipment utilization analysis

### Visualization
- Bar charts
- Line charts
- Pie charts
- Histograms

### Dashboard
- Interactive filters
- Real-time statistics
- Data exploration table
- CSV export functionality
